Architecture explainer · Sp2736/mastery-os

A learning OS that commits to you.

Mastery OS is a gamified upskilling tracker with no database and no AI calls. Every task you finish becomes a real Git commit, and every screen, score and badge is computed locally from flat JSON.

01

The big idea: Git is the database

Mastery OS targets Vercel’s free tier, so instead of Postgres or Supabase it keeps state in /data/**/*.json. In development it reads and writes the local disk. In production it commits the changed JSON back to the repo through Octokit, so your discipline shows up on your GitHub contribution graph.

Reads

Bundled JSON

Typed loaders in lib/storage/readJson.ts read roadmaps, user files, quotes and achievement definitions straight from /data.

Writes

fs in dev, commits in prod

NODE_ENV picks the adapter. Same call signature either way, so route handlers never know which one ran.

Rules (AGENTS.md / CLAUDE.md)

Guardrails for coding agents

No DB or ORM, no external LLM APIs, no visible login form, userId validated before any path is built, motion wrapped in a reduced-motion hook.

04

The headless access gate

There is no login form, password or OAuth. Visiting / unauthenticated renders AccessGate: a generic “Access Denied” shield with the real dashboard never mounted. Authentication happens only through a function the gate registers on the window.

window.getAccess('your-username')   // run in the browser console
// → POST /api/auth/session → sets httpOnly cookie "mastery_session"
Token

Signed JWT

lib/auth.ts signs {userId} with HS256 via jose, 7-day expiry, using SESSION_SECRET. createSession, verifySession, clearSession.

Cookie

Hardened flags

httpOnly, secure in production, sameSite=lax, path /, 7-day expiry. DELETE /api/auth/session logs out (LogoutButton).

Request gate

proxy.ts rules

  • Skips /_next, /api/public, /api/flex, /api/auth/session, and any path containing a dot
  • No cookie: API gets 401 JSON, pages redirect to /
  • Valid cookie on / redirects to /dashboard
  • Invalid token: cookie deleted, redirect or 401
Isolation

Path-traversal shield

Private routes take the user from the verified JWT only, never from URL or query. validateUserId allowlists the id before any file path is built.

Gate theatre

Quote on the shield

The gate types out a daily quote letter by letter, can speak it aloud, has a mute toggle, and fades out into the dashboard once access is granted (states: denied, authenticating, granted).

05

The Git-backed storage engine

Everything funnels through lib/storage/writeJson.ts. Two shapes of write exist, and both switch on NODE_ENV.

Single file

writeJson / writeUserJson

Dev: fs.writeFileSync with directories created as needed. Prod: look up the file’s blob SHA, then update via the Contents API under data/<path>.

Many files

writeBatchJson / writeMultipleUserJson

One atomic commit for several files, so a single user action never leaves a half-written state.

getRef(heads/main) → getCommit → createTree(base_tree, blobs)
  → createCommit(parents:[latest]) → updateRef
  • Octokit is a lazy module-level singleton, created only on the first production write and reused on warm instances.
  • Env: GITHUB_TOKEN (required), GITHUB_OWNER, GITHUB_REPO, optional GITHUB_BRANCH (defaults to main).
  • Default commit message lists the touched files plus a timestamp; callers can pass their own.
  • The README also documents a 3–5 second write-through cache to avoid redundant commits on rapid UI updates.
06

Markdown → roadmap AST

You write a roadmap in Markdown and the parser (lib/parser/index.ts, driven by scripts/parse-roadmaps.ts) turns it into JSON the app can score and schedule.

Structure

Heading → hierarchy

  • # roadmap title
  • ## phase (phase-1, …)
  • ### week, then task lines become nodes
Node fields

What a node carries

id, title, track, type, estimatedMinutes, difficulty (easy/medium/hard), dependencies, resources, checkpoint flag. Weeks list their tracks; roadmaps list all tracks.

Stable IDs

History survives edits

"node-" + sha1(roadmapId + phaseTitle
 + weekTitle + rawLineText).slice(0,10)

Unchanged lines keep their progress. Renamed or deleted tasks are archived into progress.json.archived[], never dropped.

RoadmapWeeksNodesAccentSource markdown

8-Week Web Dev856#6366f1web-dev-roadmap.md

A manifest (_manifest.json) indexes roadmaps; RoadmapSwitcher on the dashboard flips between them. The 6-month plan spans DSA/CP, business, finance and critical thinking.

07

The rollover scheduler

lib/storage/dateShift.ts computes “today’s tasks” on the fly instead of storing a calendar. Nodes are flattened in roadmap order and mapped to days from each roadmap’s start date.

  • Rollover: incomplete tasks from earlier days carry forward, flagged isRolledOver with daysOverdue and originalDate.
  • Cascade: future target dates shift by the number of overdue tasks, so the plan slides rather than piles up.
  • Persistence: shifted schedule and profile metadata are saved in one atomic commit via writeMultipleUserJson.
  • Display order in TodaysTasks: overdue first (most overdue on top), then today’s tasks, then completed.

09

The game engine

XP per node

floor(baseXP × multiplier)

Defaults: base 20, easy ×2, medium ×5, hard ×8, so 40 / 100 / 160 XP. Both are editable in Settings (base 5–100). Repeat completions award 0.

Levels

100 · n1.5

xpForLevel(n) = floor(100 × n^1.5); levelFromXP climbs until the next threshold exceeds total XP. Crossing a level sets lastLevelUp in the store.

Streak

Daily chain

Tracks current, longest and lastActiveDate; updated by node and LeetCode completions.

10

Local insights, no AI

  • Pearson correlations (lib/insights/correlations.ts): mood ↔ focus, sleep ↔ nodes completed, energy ↔ focus, days active ↔ nodes per day. Needs at least 3 journal entries; returns values in [-1, 1] plus human-readable summary lines.
  • Finish-date forecast (predictFinishDate): per-roadmap velocity in nodes per day projects remaining nodes forward; with zero progress it falls back to the roadmap’s planned duration.
  • Pace status in retrospectives: actual vs expected completion; at least 105% is ahead, at least 90% is on-track, otherwise behind.
  • Weekly reports are compiled from tracked metrics only, so nothing is hallucinated and no data leaves the app.

Look, motion & voice

Dynamic accent palette

deriveAccentPalette.ts derives a full HSL palette from the profile’s themeAccent {h,s,l}; the default hue is 238.

Track colours & icons

trackPalette.ts hashes the track name into a curated 12-colour dark-mode palette, so a track’s colour is always stable. trackIcons.ts maps tracks to lucide icons.

Motion system

easings.ts: easeOutExpo, easeInOutCubic, a playful spring, and usePrefersReducedMotion. Animations downgrade to fades or instant changes for reduced-motion users.

Daily quotes

getDailyQuote.ts picks deterministically from quotes.json and tracks shown indexes so quotes do not repeat until the pool is exhausted. Categories: discipline, consistency, entrepreneurship, wealth, leadership, engineering, software, stoicism, fitness, ambition. Falls back to “Discipline equals freedom.”

Spoken quotes

speakQuote.ts uses the Web Speech API and prefers deep English male voices by name priority, filtering out known female voices when no match exists.

Shared components

AccessGate, SidebarNav, TopBarXP, TopBarQuote, LogoutButton, ProgressRing, RoadmapSwitcher, TodaysTasks.

Ops & onboarding

GITHUB_TOKEN=…    # fine-grained PAT, contents read/write
SESSION_SECRET=…  # long random string
GITHUB_OWNER=Sp2736
GITHUB_REPO=mastery-os
  • Local: npm install, create .env.local, npm run dev, then window.getAccess('…') in the console.
  • Deploy: import into Vercel, add the four env vars, deploy; NODE_ENV=production turns writes into commits.
  • New user (for-new-user.md): fork the repo, add the lowercase username to the allowlists in readJson.ts, writeJson.ts, AccessGate.tsx and the /api/auth/session Zod enum, copy data/users/swayam to the new name and fix each userId, create a PAT, set env vars, deploy.
  • Dev commands: npm run dev | build | start | lint.

Sharp edges

Worth knowing when you extend it.
  • The user allowlist is hard-coded to 'swayam' in several places, so multi-user needs code edits, not config.
  • SESSION_SECRET has a dev fallback string in both proxy.ts and auth.ts; production must set a real one.
  • The README mentions an /api/admin/reparse route and a (gate) route group that are not in the current tree; reparsing is done via scripts/parse-roadmaps.ts.
  • CLAUDE.md references scripts/generate-quotes.ts, but only parse-roadmaps.ts and seed-data.ts exist in scripts/.
  • CLAUDE.md and AGENTS.md say middleware.ts; the project uses proxy.ts, the Next.js 16 name.
  • Every write is a real commit, so heavy UI activity means many commits; batch writes help but do not remove this.
